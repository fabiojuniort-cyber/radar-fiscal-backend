# Arquivos que o Fábio precisa salvar manualmente (lote 1)

Para que servem: as amostras oficiais (entrega 9) e os cabeçalhos e rodapés (entrega 4). Os portais abaixo não respondem a este ambiente.

**Como salvar (vale para todos):**
1. Abra o link no navegador do computador.
2. Se for página: aperte Ctrl+S (no Mac, Cmd+S) e escolha **"Página da Web, somente HTML"**. Se abrir um PDF: use o botão de download.
3. **Não renomeie** o arquivo.
4. Arraste o arquivo para a conversa e escreva, ao lado, o link e a data/hora em que salvou.

**Resultado esperado:** o EXEC registra URL, data, SHA-256 e origem `obtido manualmente pelo Fábio — reprodução salva pelo navegador`. A reprodução nunca é chamada de original.

**Não envie o 52/91 nem o 100/97.**
