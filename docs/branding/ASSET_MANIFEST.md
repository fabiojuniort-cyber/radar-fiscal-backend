## Consumo no frontend
Quando o repositório web for criado, copiar os masters aprovados para uma pasta de assets estáticos do frontend e manter os nomes semânticos acima.

O site e o app devem derivar o sistema visual do mesmo kit: navy, azul, ciano, teal, camadas, morros/ondas, feixes e cantos arredondados.
