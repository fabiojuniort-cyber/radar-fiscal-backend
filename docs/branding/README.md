# Branding — TriBusca

Este diretório registra a identidade oficial da marca TriBusca para uso por todas as frentes do projeto.

## Regra principal
O **Brand Kit TriBusca v1** é a fonte visual oficial. Ele deve ser usado em qualquer necessidade visual, inclusive no futuro site público e na aplicação autenticada.

Os masters binários estão preservados no acervo do projeto em:

`/TriBusca/Branding/v1`

Consulte:
- `BRAND_MANUAL_V1.md` — regras de marca.
- `ASSET_MANIFEST.md` — nomes e uso dos arquivos oficiais.

Não redesenhar ou regenerar o logo quando já existir um master aprovado.
