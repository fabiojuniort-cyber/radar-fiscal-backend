# SEFAZ-SP — capturas manuais (R6)

Páginas oficiais do RICMS/2000 em legislacao.fazenda.sp.gov.br, salvas pelo proprietário
(Chrome/Edge, Ctrl+S → "Página da Web, somente HTML"), sem edição, e enviadas à COORD.

- A URL oficial de cada arquivo é a do `<link rel="canonical">` presente no próprio HTML.
- O horário tem como limite superior a recepção pela COORD (2026-11-25 02:22 UTC).
- Os hashes estão em `MANIFEST.csv`.

Uso: evidência de proveniência das células SEFAZ-SP · RICMS artigo (pequeno e médio) do R6.
O EXEC deve comparar com as capturas arquivadas. Divergência de texto deve ser reportada,
nunca ocultada. Não marcar `urlVerified`/`verified` sem essa comparação.
